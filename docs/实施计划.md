## 阶段 0：项目初始化与依赖安装

**目标**：使用 shadcn/ui 初始化 Next.js 15 项目，安装所有依赖，确保开发环境就绪。

**操作步骤**：
1. 使用 `npx shadcn@latest init --yes --template next --base-color slate` 初始化项目
2. 安装核心依赖：`@prisma/client`, `ai`, `@ai-sdk/openai`, `zod`, `prisma` (dev)
3. 安装可选 AI Provider：`@ai-sdk/anthropic`, `@ai-sdk/google`, `@ai-sdk/deepseek`, `@ai-sdk/groq`
4. 安装 UI 依赖：`@fullcalendar/react`, `@fullcalendar/daygrid`, `@fullcalendar/timegrid`, `@fullcalendar/interaction`, `@tanstack/react-table`, `recharts`, `lucide-react`
5. 安装备份依赖：`archiver`, `decompress`
6. 配置 `tsconfig.json` 路径别名（`@/*` → `./src/*` 或 `./*`）
7. 创建 `.env.local` 模板（数据库 URL、MODEL、各 AI API Key）

**测试验证**：
- `npm run dev` 能正常启动，无报错
- 浏览器访问 `http://localhost:3000` 显示默认 Next.js 页面

## 阶段 1：数据库配置与全局布局

**目标**：配置 PostgreSQL + Prisma，创建数据库 Schema，实现全局侧边栏/顶部栏布局。

**操作步骤**：
1. 创建 `docker-compose.yml`（PostgreSQL + 可选 pgAdmin）
2. 启动 Docker 容器：`docker-compose up -d`
3. 创建 `prisma/schema.prisma`，定义所有模型（Student, Coach, Course, Attendance, Grading, Competition, Camp）和枚举
4. 执行首次迁移：`npx prisma migrate dev --name init`
5. 生成 Prisma Client：`npx prisma generate`
6. 创建 `lib/prisma.ts`（单例模式）
7. 创建 `lib/utils.ts`（通用工具函数）
8. 创建全局布局 `app/layout.tsx`：含侧边栏导航（Sidebar）+ 顶部栏（Header）
9. 创建 `app/globals.css`，配置 Tailwind 全局样式
10. 创建空白占位页面：`app/page.tsx`（仪表盘）、`app/students/page.tsx`、`app/coaches/page.tsx`、`app/calendar/page.tsx`、`app/attendance/page.tsx`、`app/ai/page.tsx`、`app/backup/page.tsx`

**测试验证**：
- `docker-compose ps` 显示 postgres 容器 healthy
- `npx prisma studio` 能打开并看到所有表结构
- `npm run dev` 启动后，侧边栏导航正常显示，点击各菜单项可切换路由
- 各占位页面能正常访问

## 阶段 2：学员管理（核心功能）

**目标**：实现学员的完整 CRUD（增删改查）、照片上传、学员详情页。

**操作步骤**：
1. 创建学员 API：`app/api/students/route.ts`（GET 列表/POST 新增）、`app/api/students/[id]/route.ts`（GET/PUT/DELETE）
   - GET 列表支持 `?search=&status=&page=` 查询参数
   - DELETE 为软删除（status → inactive）
2. 创建文件上传 API：`app/api/upload/route.ts`（POST 上传/DELETE 删除），支持学员和教练照片
3. 创建 `public/uploads/students/` 和 `public/uploads/coaches/` 目录
4. 创建复用组件：
   - `components/ui/avatar.tsx`（头像组件）
   - `components/students/photo-capture.tsx`（照片采集：摄像头+文件上传）
   - `components/students/student-form.tsx`（学员表单，新增/编辑共用）
   - `components/students/student-table.tsx`（学员表格，含搜索/筛选/分页）
5. 创建页面：
   - `app/students/page.tsx`（学员列表页）
   - `app/students/new/page.tsx`（新增学员）
   - `app/students/[id]/page.tsx`（学员详情页——只读展示）
   - `app/students/[id]/edit/page.tsx`（编辑学员）
6. 学员详情页内容：个人信息卡（含环形进度图展示剩余课时）、成长时间线、比赛记录表、集训记录卡、考勤统计柱状图+最近记录
7. 身份证加密存储：在 API 层使用 Node.js `crypto` 模块对称加密/解密

**测试验证**：
- API 测试（可用 curl 或浏览器 DevTools）：
  - POST `/api/students` 能新增学员，返回正确数据
  - GET `/api/students` 支持搜索和分页
  - GET `/api/students/[id]` 返回学员详情含关联记录
  - PUT `/api/students/[id]` 能更新信息
  - DELETE `/api/students/[id]` 软删除成功
  - POST `/api/upload` 上传图片成功，文件写入目录
- 页面测试：
  - 学员列表页正常显示，搜索/筛选/分页可用
  - 新增学员表单可提交，照片可上传
  - 学员详情页美观展示所有信息
  - 编辑页面预填充数据正常

## 阶段 8：数据备份与恢复

**目标**：实现一键备份（pg_dump + 照片 ZIP）和 ZIP 导入恢复。

**操作步骤**：
1. 创建 `app/api/backup/route.ts`：
   - GET：导出备份 → pg_dump SQL + 打包 uploads/students/ + manifest.json → ZIP 下载
   - POST：导入备份 → 解压 ZIP → 校验 manifest → 先备份当前数据 → psql 导入 SQL → 解压照片 → 清理临时文件
2. 创建 `app/backup/page.tsx`：备份与恢复页面
   - 备份数据卡片：说明 + "立即备份"按钮
   - 恢复数据卡片：上传区域 + 确认恢复模态框 + 进度提示
3. 确保 Docker/生产环境 `pg_dump` 和 `psql` 可用（README 中说明）

**测试验证**：
- API 测试：
  - GET `/api/backup` 返回 ZIP 文件，内含 SQL 和照片
  - POST `/api/backup` 上传 ZIP 后成功恢复数据
  - 恢复前自动创建当前数据快照
- 页面测试：备份页按钮和上传区域正常，恢复有二次确认

## 风险与注意事项

| 风险点 | 缓解措施 |
|--------|----------|
| FullCalendar 与 Next.js SSR 兼容性 | 使用 `'use client'` 封装，或动态导入 `next/dynamic` |
| 照片上传大文件内存溢出 | 限制 5MB，流式写入文件系统 |
| Prisma Client 热重载多实例 | 严格使用单例模式 `lib/prisma.ts` |
| AI 工具调用参数格式错误 | 使用 Zod 严格校验工具参数 |
| 备份恢复误操作覆盖数据 | 导入前自动快照 + 二次确认弹窗 |
| 并发点名扣减课时超扣 | 使用 PostgreSQL 事务 + `remainingSessions: { gt: 0 }` 条件 |
| Next.js 16 静态生成要求 | `useSearchParams()` 等 CSR hook 必须包裹在 `<Suspense>` 边界内 |
